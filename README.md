## Run Locally

No additional frameworks or build tools are required to view the portfolio.

1. Clone the repository:

   ```bash
   git clone https://github.com/giakiet00/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser.
